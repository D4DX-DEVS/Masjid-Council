# മസ്ജിദ് കൗൺസിൽ കേരളയുടെ

# മസ്ജിദ് ഫണ്ടിലേക്ക് അപേക്ഷ സമർപ്പിക്കുമ്പോൾ ശ്രദ്ധിക്കേണ്ട കാര്യങ്ങൾ

1.  **MCK യിൽ അഫിലിയേറ്റ് ചെയ്ത മസ്ജിദുകൾക്ക് വേണ്ടിയുള്ള സംവിധാനമാണിത്.**
    അഫിലിയേറ്റ് ചെയ്യാത്ത പള്ളികളുടെ അപേക്ഷ പരിഗണിക്കുകയില്ല.

2.  **എല്ലാ മാസവും ആദ്യത്തെ വെള്ളിയാഴ്ച ജുമുഅക്ക് ശേഷം മസ്ജിദ് ഫണ്ട് സമാഹരിക്കുകയും
    കേന്ദ്രത്തിലടക്കുകയും ചെയ്യുന്ന പള്ളികൾക്കാണ് സഹായത്തിന് അർഹതയുള്ളത്.**

3.  **പള്ളികളുമായി ബന്ധപ്പെട്ട അറ്റകുറ്റപ്പണികൾക്ക് വേണ്ടിയാണ് അപേക്ഷ സമർപ്പിക്കേണ്ടത്.**
    പുതിയ പള്ളി നിർമ്മാണത്തിനോ പള്ളിയുമായി ചേർന്ന് നിൽക്കുന്ന മറ്റു സംവിധാനങ്ങൾക്കോ
    (മദ്രസ, ലൈബ്രറി etc.) സഹായം അനുവദിക്കുകയില്ല.

4.  **മസ്ജിദ് പ്രസിഡന്റ് / സെക്രട്ടറിയാണ് അപേക്ഷ സമർപ്പിക്കേണ്ടത്.**

5.  **സഹായം ആവശ്യമായ ഇനത്തിന്റെ പ്ലാൻ, എസ്റ്റിമേറ്റ് എന്നിവ അപേക്ഷയോടൊപ്പം
    സമർപ്പിക്കേണ്ടതാണ്.**

6.  **ഒരു തവണ സഹായം അനുവദിക്കപ്പെട്ട മസ്ജിദുകൾക്ക് പിന്നീട് നാല് വർഷത്തിന് ശേഷം മാത്രമേ
    അപേക്ഷ സമർപ്പിക്കാൻ അർഹതയുള്ളൂ.**

7.  **സഹായം ആവശ്യമായ മസ്ജിദിന്റെ ബാങ്ക് പാസ് ബുക്കിന്റെ കോപ്പി** (അക്കൗണ്ട് നമ്പർ,
    അക്കൗണ്ട് ഹോൾഡറുടെ പേര് ഉള്ള ഭാഗം) അപേക്ഷയോടൊപ്പം ചേർക്കണം. **ചെക്ക് വഴി മാത്രമേ
    സഹായം ലഭിക്കൂ.**

8.  **അക്കൗണ്ട് മസ്ജിദ് / മാനേജിംഗ് കമ്മിറ്റി / ട്രസ്റ്റിന്റെ പേരിലുള്ളതായിരിക്കണം.**
    ജോയിന്റ് അക്കൗണ്ടിലേക്കോ മറ്റു സ്ഥാപനങ്ങളുടെ അക്കൗണ്ടിലേക്കോ ഈ ഇനത്തിലുള്ള ഫണ്ട്
    കൈമാറാൻ നിയമപരമായി തടസ്സമുണ്ട്.

9.  **സഹായം സ്വീകരിച്ചതിന്റെ റസീപ്റ്റ് മസ്ജിദ് കൗൺസിൽ കേരളക്ക് നൽകേണ്ടതാണ്.**
